### 📌 Featured Projects

#### 🤖 [InterviewIQ — AI Mock Interview Platform](https://github.com/AryanIyer29)
Real-time AI-driven mock interview system that evaluates spoken responses end to end.
- Speech-to-text via Groq Whisper, response evaluation via LLaMA 3.3-70B, NLP scoring with spaCy
- FastAPI AI engine + Node.js/Express + React/Vite full-stack app, connected over a locked-down architecture (browser ↔ FastAPI over WebSocket, browser ↔ Node ↔ FastAPI over REST)
- PDF report generation with ReportLab, MongoDB persistence, Google OAuth-gated access

#### 🏛️ beX Auction — Live Bidding Platform
India-focused live auction/bidding platform built across three coordinated codebases.
- FastAPI + PostgreSQL backend, Flutter mobile app, and a Next.js 15 / React 19 web app
- Web frontend built with Tailwind, Zustand, TanStack Query, and shadcn-style UI primitives
- Currently undergoing a design pass toward a clean, established marketplace look (inspired by Bring a Trailer, Catawiki, StockX)

#### 🧹 SAGE — Storage Analysis & Guidance Engine
A fully local, offline conversational AI assistant for personal disk cleanup — no paid APIs.
- Drive scanning, SQLite metadata store, duplicate detection via hashing, and file categorization
- Conversational, evidence-backed chat layer using Chroma vector search + Sentence-Transformers
- Locally-hosted LLM inference via Ollama (LLaMA 3.1 8B / Mistral 7B / Phi-3 Mini), orchestrated with LangChain/LangGraph
- Safe, reversible deletion through a holding-folder mechanism

#### 🛡️ Malware Detection System
ML-based malware detection with real feature extraction, shipped as both CLI and GUI tools, built with scalability and extensibility in mind.

#### 📜 AI Policy Compliance Bot
An AI system that automatically analyzes policy violations and generates intelligent compliance suggestions, combining a rule engine with AI inference for enterprise automation workflows.
